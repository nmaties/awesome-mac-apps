# Contributing

Thanks for wanting to help. This list is generated every day from [Mac Browse](https://macbrowse.com/?ref=github), so `README.md` should not be edited by hand. A pull request that changes it gets overwritten by the next update.

## Add an app

[Submit it on Mac Browse](https://macbrowse.com/submit?ref=github). Each app is reviewed there, and it shows up here the day after it is approved. You can submit your own app or one you love.

## Fix or remove an app

- **Your own app:** sign in on Mac Browse and edit it from My Apps. Changes show up here the next day.
- **Someone else's app** (broken link, wrong category, discontinued): open an issue in this repository and it will be fixed on Mac Browse.
